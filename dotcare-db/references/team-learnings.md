# Team learnings

Facts the team confirmed during real work that the original study missed or got wrong. Append new entries at the bottom; never delete one. If an entry is later proven wrong, add a new entry that corrects it.

Each entry:

```
## YYYY-MM-DD: <short title>
- Type: new fact | correction | clarification
- Module/schema: <e.g. VisitMgt, Billing>
- Learned: <what is true>
- Replaces: <reference file/claim it corrects, or "n/a">
- Evidence: <live DB query, code path, ADO item, or user confirmation>
```
