# Definition of Ready (DoR)

The DoR is the checklist a User Story must pass before it is allowed into Sprint Planning. You are the enforcer of this checklist.

## DoR Checklist

1.  [ ] The User Story is written in the correct format (As a... I want... So that...).
2.  [ ] The Acceptance Criteria are defined using Given/When/Then format.
3.  [ ] All external dependencies (e.g., UI/UX designs, 3rd party API access) are identified and resolved.
4.  [ ] The story has passed the INVEST check.
5.  [ ] Non-functional requirements (security, performance) have been considered and attached if applicable.

**Action:** Do not allow any story to proceed if this checklist is not 100% complete. Instruct the user on what is missing.
